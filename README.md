# ✂️ VK Booking & Referral Bot

VK-бот для онлайн-записи клиентов в салон и реферальной программы с начислением и списанием бонусов для платформы **ВКонтакте**.

Бот полностью сохраняет и воспроизводит функционал Telegram-версии с адаптацией под особенности API ВКонтакте.

---

## 🚀 Стек технологий
- **Python 3.10+** (протестировано на Python 3.14)
- **vkbottle 4.x** (современный асинхронный фреймворк для ботов ВКонтакте)
- **SQLite** (режим WAL, пул соединений)
- **python-dotenv**

---

## 📋 Основной функционал
- ✂️ **Онлайн-запись**: кнопка перехода к виджету онлайн-записи в один клик.
- 📍 **Геолокация и адрес**: отправка точки на карте и ссылки на Яндекс Карты прямо в чат.
- 🧴 **База знаний по уходу**: статьи и советы по укладке и бороде с каталогом товаров на Ozon (через инлайн-кнопки).
- 🎁 **Реферальная программа**:
  - Персональные ссылки `https://vk.me/<сообщество>?ref=ref_<id>` (а также поддержка ввода текстового кода `ref_<id>`).
  - Уведомление реферера в личные сообщения при регистрации друга.
  - Начисление бонуса после первого подтверждённого визита.
  - Просмотр статистики и баланса бонусов.
- ⚙️ **Админ-панель** (`/admin` или кнопка для админов):
  - Инлайн-интерфейс подтверждения визитов рефералов.
  - Списание бонусов в счёт оплаты с автоматическим уведомлением клиента.
  - Постраничная навигация (пагинация) в рамках лимитов клавиатур ВКонтакте.

## ⚙️ Настройка сообщества ВКонтакте

Для работы бота необходимо настроить группу ВКонтакте:

1. **Включить сообщения сообщества**:
   - Откройте вашу группу ВКонтакте -> **Управление** -> **Сообщения**.
   - Переключите статус на **Включены**.
   - Нажмите «Сохранить».

2. **Включить возможности ботов**:
   - В том же разделе **Управление** -> **Сообщения** -> **Настройки для бота**.
   - Переключите **Возможности ботов** на **Включены**.
   - Отметьте галочку **Добавить кнопку «Начать»**.
   - Нажмите «Сохранить».

3. **Включить Long Poll API**:
   - В меню группы перейдите в **Управление** -> **Работа с API** -> вкладка **Long Poll API**.
   - Переключите статус на **Включен**.
   - Перейдите на соседнюю вкладку **Типы событий** и отметьте:
     - ✅ **Входящие сообщения**
     - ✅ **Действие с сообщением** (для работы интерактивных кнопок)
   - Нажмите «Сохранить».

4. **Создать ключ доступа (токен)**:
   - В том же разделе **Работа с API** перейдите на вкладку **Ключи доступа**.
   - Нажмите **Создать ключ**.
   - Обязательно отметьте два права:
     - ✅ **Разрешить приложению доступ к управлению сообществом** (необходимо для подключения LongPoll сервера)
     - ✅ **Разрешить приложению доступ к сообщениям сообщества**
   - Подтвердите создание и скопируйте полученный ключ доступа (начинается с `vk1.a...`) в файл `.env`.

## 🛠 Установка и запуск

### 1. Создание виртуального окружения
```bash
python3 -m venv .venv
source .venv/bin/activate  # На macOS / Linux
# .venv\Scripts\activate   # На Windows
```

### 2. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 3. Настройка окружения
Создайте файл `.env` на основе примера:
```bash
cp .env.example .env
```

Заполните обязательные переменные в `.env`:
```env
VK_TOKEN=ваш_токен_сообщества
ADMIN_IDS=ваш_vk_id
```

> 💡 **Как узнать свой VK ID**:
> Запустите бота и отправьте ему в сообщения команду `/myid` — бот пришлёт ваш цифровой идентификатор.

### 4. Запуск бота
```bash
python3 main.py
```

После старта бот автоматически подключится к API ВКонтакте, определит параметры вашего сообщества и начнет приём сообщений.
